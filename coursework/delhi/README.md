# 德里氣溫時間序列：早期學習專題

**作者：王邱鈺為。** 這份早期時間序列課程作品呈現從圖形觀察、季節性辨識到模型診斷的學習過程。

方法涉及 ADF、ACF／PACF／EACF、季節 ARIMA、殘差診斷、Fourier regressors、外生變數與 ARIMA errors。學習重點是把季節結構與模型診斷連結，並反思驗證時何種資訊真的可得。

[Drive 課堂作品集](https://drive.google.com/drive/folders/1Jz69LXrlcab4hEv5CXLoq1vukDnb714n) 的「04_德里氣溫_早期學習節選.pdf」共 10 頁：新增說明頁加原第 6、13、26、28、30、32、34、35、36 頁。

已知限制包括日資料分析的 lag 12／365 混用；外生濕度、風速若使用未來觀測值，預測屬於條件式設定；2017 年 1 月曾用於調整，不能再當作完全未接觸的最終測試集。本次提供原報告節選，未重跑原實驗；原資料不包含在公開作品集。

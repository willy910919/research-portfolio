# MLE 與 MAP：樣本量及先驗敏感度

**作者：王邱鈺為；個人獨作。** 這份課程作品比較最大概似估計與最大後驗估計，整理常態共軛模型、精確度加權與樣本資訊如何平衡先驗資訊。

內容以推導、模擬圖形與模型檢查說明樣本量改變、先驗強弱及先驗假設不符時的差異，並包含後驗預測檢查的學習。透過理論與圖形對照，練習判讀估計結果對模型假設的依賴。

原碼與全部設定尚未在本次核對，本次提供理論整理與原報告節選。結果應在報告的樣本量與先驗設定下解讀；後續可補上完整模擬設定、誤差量化及可重現程式。

# 抽樣方法模擬研究

**作者：王邱鈺為。** 3,000 次抽樣模擬與報告基本由本人獨作。這裡保存 [sampling_final_report.R](sampling_final_report.R) 原始 475 行程式，未改動演算法及參數，也沒有包入原輸出表、圖或任何真實個體資料。報告見 [Drive 課堂作品集](https://drive.google.com/drive/folders/1Jz69LXrlcab4hEv5CXLoq1vukDnb714n) 的「03_抽樣方法模擬_課程作品.pdf」。

## 問題與方法

在固定有限母體下，以 3,000 次 Monte Carlo 抽樣比較估計值的偏差、變異、MSE、區間涵蓋率及相對效率，觀察不同抽樣設計及輔助資訊的影響：

- 簡單隨機抽樣，包含放回與不放回情境。
- 比率估計與輔助變數相關性。
- 分層抽樣的比例配置與 Neyman 配置。
- 兩階段群集抽樣及群內相關設定。

程式設定 `set.seed(20260627)`、`iter <- 3000`，自行生成模擬母體，只使用 base R。隨機種子有助追溯；R 版本或數值環境仍可能造成細微差異。

## 執行

在這個資料夾開啟終端機：

```sh
Rscript sampling_final_report.R
```

程式會執行全部實驗，寫出 `output/tables/` 的彙總表和 session info，以及 `output/figures/` 的 PNG。執行時會覆寫同名本地輸出；`.gitignore` 已排除產生檔。此次公開整理只檢查 R 語法與來源 SHA，沒有重跑完整 3,000 次實驗，因此未宣稱新的重現數值。

## 已知限制

程式中 `actual_icc` 實際存放生成模型的指定 ICC，不能將欄位名稱解讀成有限母體實現 ICC。Neyman 配置使用已知分層標準差，代表理想化資訊條件。模擬涵蓋率與效率取決於此處的有限母體、參數及估計量，不能直接推廣至任意真實調查。

這個作品展示將抽樣理論轉為程式、實驗設計比較與結果判讀的學習。

# 課堂學習作品

這一區展示統計學習的理論、程式、模型判讀及反思。個人分工及各作品學習重點分別列示。課程圖文附件放在 [Drive 課堂學習作品集](https://drive.google.com/drive/folders/1Jz69LXrlcab4hEv5CXLoq1vukDnb714n)，GitHub 不上傳原講義或整份教科書。

| 作品 | 貢獻 | 內容 |
|---|---|---|
| [抽樣方法模擬](sampling/README.md) | 基本由本人獨作，署名王邱鈺為。 | 真實完整 R 程式、3,000 次模擬設定、方法與限制。 |
| [多變量貝氏](bayesian/README.md) | 小組作品；負責數學原理及實作代碼說明。 | 多變量常態、條件分布、Gibbs 與缺失資料。 |
| [MLE／MAP](mle-map/README.md) | 個人獨作。 | 常態共軛估計、樣本數、先驗敏感度與預測檢查。 |
| [德里氣溫](delhi/README.md) | 幾乎全份由本人完成。 | 早期季節時間序列專題與驗證限制。 |

這些課程作品串連估計理論、模擬設計、缺失資料及時間序列驗證，呈現逐步建立統計分析能力的學習歷程。

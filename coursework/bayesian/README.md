# 多變量常態模型與缺失資料處理

**性質：貝氏分析課程小組報告。本人貢獻：數學原理與實作代碼說明。** 原報告保留共同作者署名。

學習範圍包含多變量常態模型、半共軛先驗、full conditional distributions、Gibbs sampling，以及 MCAR／MAR／MNAR 與缺失資料的條件分布。重點是說明參數與缺失值如何交替抽樣，理解先驗、共變異結構和條件假設如何影響推論。

成果包含理論整理與程式解讀，教材範例及程式依原來源標示。本次整理提供報告節選，未重跑原程式；個體健康資料不包含在作品集。
